# Prosper Loan Data Analysis

## 📌 Project Overview

This project explores the Prosper Loan Dataset using Python to identify patterns in borrower characteristics, loan amounts, interest rates, and loan terms through Exploratory Data Analysis (EDA).

The analysis uses data visualization to investigate relationships between loan amounts and factors such as income range, employment status, and loan term, providing insights into borrower and lending patterns.

## 🎯 Objectives

- Explore the structure and characteristics of the dataset.
- Analyze the distributions of loan amounts and borrower interest rates.
- Examine borrower distributions across income ranges, employment statuses, and loan statuses.
- Investigate how loan amounts vary across income and employment groups.
- Explore the relationship between loan amounts and borrower interest rates.
- Compare loan amounts across different loan terms.
- Identify unusual values and outliers through visualization.

## 🛠️ Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Dataset Overview

The Prosper Loan Dataset contains *113,937 records and 81 columns*, covering borrower characteristics and loan information.

### Key Variables

| Variable | Description |
|---|---|
| LoanOriginalAmount | Original loan amount |
| BorrowerRate | Interest rate charged to the borrower |
| LoanStatus | Status of the loan |
| EmploymentStatus | Borrower's employment status |
| IncomeRange | Borrower's income category |
| Term | Loan duration in months |

## 🔎 Data Analysis Process

1. Imported and inspected the dataset.
2. Examined column names, data types, and dataset structure.
3. Explored individual variables using descriptive statistics and visualizations.
4. Created histograms, count plots, box plots, and scatter plots.
5. Investigated relationships between loan amounts, income ranges, employment status, interest rates, and loan terms.
6. Recorded observations and summarized the findings.

## 💡 Key Findings

- *Loan Status:* Current and Completed loans were the most common categories in the dataset.
- *Employment Status:* Employed borrowers represented the largest employment group.
- *Income and Loan Amount:* Borrowers in higher income ranges generally tended to receive larger loans.
- *Employment and Loan Amount:* Loan amounts varied across employment groups.
- *Loan Amount and Interest Rate:* The scatter plot suggested that larger loans generally tended to have lower borrower interest rates.
- *Loan Term:* Loans with a 60-month term generally had higher loan amounts than loans with 36-month and 12-month terms.
- *Outliers:* Box plots revealed unusually large loan amounts among some borrowers.

These findings describe observed patterns and do not establish cause-and-effect relationships.
